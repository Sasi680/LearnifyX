# LearnifyX

**Our AI-powered study companion for smarter and easier learning.**

## About

LearnifyX is a student-focused learning companion concept designed to make self-learning simpler, more interactive, and personalized.

## Features

- Smart Study
- AI Assistance
- Practice & Assessment
- Progress Tracking
- Student-friendly interface

## Project Status

This repository contains the LearnifyX web prototype prepared for the hackathon project presentation.
